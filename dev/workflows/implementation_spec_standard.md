# Implementation Spec Standard

跨越兩個以上 architecture layers 的功能，在實作前記錄：

- Goal / non-goals
- Domain types and invariants
- Commands and mutation owner
- Selectors and rendered states
- Persistence payload impact
- Error and recovery behavior
- Test matrix

Spec 放在 `dev/docs/plans/`，完成後保留作為設計歷史，並在狀態欄標示 implemented 或 superseded。
