# 航海增量遊戲設計文件

> 版本：v3.0（單角色 / 無 Prestige / 副官系統版）

---

## 一、設計定位

### 核心概念

以大航海時代為題材的 Melvor-like 增量遊戲。

玩家培養一名永續成長的主角船長，透過 Knowledge、Skill、Action Mastery、船隻、副官與遠征系統，逐步開拓世界地圖。

| 來源                               | 吸收的層面                                                          |
| ---------------------------------- | ------------------------------------------------------------------- |
| **Melvor Idle**                    | 底層骨架：Skill / Knowledge、Action Mastery、離線進度、系統互相咬合 |
| **大航海時代 / 大航海時代 Online** | 世界觀：航線開拓、港口准入、貿易策略、語言、副官、船隻配置          |
| **Fallout Shelter**                | 母港層：基地建設、支援派駐、突發事件製造回來看一眼的鉤子            |

### 一句話定位

> 培養一名船長，招募副官、掌握知識、開拓航線，逐步把未知海域變成自己的世界。

### 不做的事

- **不做 Prestige Reset**：不重置角色、不重置帳號、不重置海域
- **不做船長退役**：主角船長永續成長，不存在世代輪替
- **不做死亡懲罰**：失敗只是報酬少於成功，不倒扣、不毀損、不砍進度
- **不做多角色主線管理**：副官是配置與支援，不是另一批需要完整養成的主角

## 二、系統結構總覽

```
主角層（永久，核心角色）
├── Captain Skill          → Event 判定 Roll 上限 / 下限 + 實戰能力
├── 裝備 / 船隻             → Base Score 組成 + 特定 Action 修正
└── 聲望 / 發現物 / 成就     → 解鎖委託、港口、遠征與副官

帳號層（永久，全局）
├── Knowledge              → Action 解鎖門檻 + Base Score 加成
└── Action Mastery          → 逐 Action 獨立熟練度，解鎖 Feature / Buff / 新 Action

海域層（永久，區域）
├── Region Familiarity      → 該海域所有 Action Mastery 加總 → 區域熟悉度 Buff
└── Action 集合             → 每個海域獨有的具名活動

副官層（配置，支援）
├── 副官能力                → 特定 Skill / Knowledge / Action 類型加成
├── 語言                    → 港口准入 / 情報 / 委託 / 交易解鎖
└── 派駐                    → 母港研究、翻譯、交易、造船、情報支援

母港層（永久，基地）
└── 設施                    → 船隻、倉庫、研究、副官招募、支援派駐
```

### 核心分工

| 系統               | 玩家理解                       |
| ------------------ | ------------------------------ |
| 主角船長           | 我本人，所有實戰成長都留在身上 |
| Knowledge          | 我懂不懂這件事                 |
| Captain Skill      | 我做不做得到這件事             |
| Action Mastery     | 我對這個活動熟不熟             |
| Region Familiarity | 我對這片海域熟不熟             |
| 副官               | 我這次帶誰來輔助               |
| 船隻               | 我用什麼工具與配置去做         |
| 遠征               | 我是否已經準備好推進世界       |

## 三、Knowledge 系統（帳號永久層）

### 定位

**概念型的長遠培養內容，綁帳號，永不消失。**

Knowledge 對應 Melvor 的 Skill，是整個遊戲最核心的永久進度。Knowledge 決定「你能不能去做某件事」——沒有考古學基礎，你不知道遺跡在哪、怎麼挖；沒有地理學和天文學基礎，你無法安全開闢遠洋航線。

Knowledge 主要影響：

- Action 解鎖門檻
- Base Score
- 遠征需求
- 母港設施研究
- 特定副官能力上限或派駐效果

### 三大類 Knowledge

#### 交易知識（商品）

| 細項   | 效果方向                       |
| ------ | ------------------------------ |
| 貴金屬 | 買賣差價、金銀套利、鑄幣廠     |
| 藝術品 | 鑑定收益、貴族委託、收藏品交易 |
| 礦物   | 原料採購效率、造船材料供應     |
| 雜貨   | 日常貿易穩定性、低風險收益     |
| 食品   | 補給成本降低、長途航行支援     |
| 家畜   | 殖民地供應鏈、港口發展委託     |
| 香料   | 高價遠洋商品、印度洋貿易核心   |
| 紡織品 | 中期核心貿易品、轉口貿易       |

#### 學術知識（學科）

| 細項   | 效果方向                             |
| ------ | ------------------------------------ |
| 神學   | 宗教遺物、修道院委託、封閉地區准入   |
| 考古學 | 遺跡發掘成功率、發現物品質           |
| 美術學 | 藝術品鑑定、貴族關係、收藏品任務     |
| 生物學 | 動植物記錄、殖民地開發、醫藥資源     |
| 地理學 | 遠洋航線解鎖、測量任務、地圖製作     |
| 天文學 | 航行時間縮短、遠洋定位、惡劣天候應對 |
| 醫學   | 疫病事件應對、船員損耗降低、遠征安全 |

#### 航海知識

| 細項     | 效果方向                         |
| -------- | -------------------------------- |
| 操帆理論 | 航行時間縮短、遠洋可達性         |
| 掌舵理論 | 暗礁、急流、狹窄航道應對         |
| 補給理論 | 長距離遠征門檻降低、航行成本控制 |
| 氣象學   | 風暴損失降低、季風航線解鎖       |
| 測量學   | 新海域探索效率、地圖品質提升     |
| 修繕學   | 船隻耐久恢復、事故損失降低       |

### 語言的處理方式

語言不作為主 Knowledge 主線，而是主要放入副官系統。

原因：

- 語言更像「鑰匙」與「配置」，不是核心長期能力
- 語言種類太多時，若全部變成主角技能，會造成雜訊
- 副官語言能自然形成大航海時代式的隊伍配置

例：

```
阿拉伯語副官
  → 紅海 / 印度洋港口准入
  → 香料情報取得率 +10%
  → 伊斯蘭學者委託解鎖

葡萄牙語副官
  → 西非商館委託解鎖
  → 好望角遠征情報需求降低
  → 西非交易 Action 報酬 +5%
```

### Breakpoint 設計原則

- **小等級給效率**：+X% 差價、縮短時間、提升成功率
- **中等級給穩定性**：降低失敗報酬折損、增加保底收益
- **大等級給新玩法**：解鎖全新 Action 類型、遠征、設施或跨海域路線

範例：

```
貴金屬 Lv.5  → 解鎖銀交易
貴金屬 Lv.15 → 解鎖金交易
貴金屬 Lv.30 → 可建立鑄幣廠
貴金屬 Lv.50 → 解鎖跨洲套利
```

### 在公式中的位置

Knowledge 影響 **Base Score** 和 **Action 解鎖門檻**，不直接影響 Roll。

## 四、Captain Skill 系統（主角永久層）

### 定位

**實操型的培養內容，綁主角船長，永不消失。**

Captain Skill 決定「你在現場能不能處理突發狀況」。風暴來了，是操帆手感在救你，不是書本知識；海盜接舷時，是白兵和炮術在決定結果，不是交易知識。

### 四大職能

| 職能         | 能力                   | 對應活動                       |
| ------------ | ---------------------- | ------------------------------ |
| **商業手段** | 會計、社交、市場判斷   | 貿易、議價、商會委託、貴族交涉 |
| **探險操作** | 挖掘、檢查、發現       | 遺跡、動植物、地圖、發現物     |
| **航行手段** | 操帆、掌舵、補給       | 航線探索、風暴、暗礁、長途遠征 |
| **海事手段** | 炮術、射擊、白兵、修繕 | 海盜、護航、私掠、艦隊戰       |

### 在公式中的位置

Captain Skill 決定 **Roll Score 的上限和下限**，是衝進「大成功」區間的關鍵。

### 能力成長路徑

- 進行交易 Action → 練會計、社交、市場判斷
- 進行探險 Action → 練挖掘、檢查、發現
- 進行航行 Action → 練操帆、掌舵、補給
- 進行海事 Action → 練炮術、射擊、白兵、修繕
- Event 額外成長：遭遇風暴 → 操帆 EXP；暗礁 → 掌舵 EXP；海盜砲擊 → 炮術 EXP；疫病 → 醫學 Knowledge EXP

### Knowledge 與 Skill 的差異

|          | Knowledge                  | Captain Skill                  |
| -------- | -------------------------- | ------------------------------ |
| 屬性     | 概念知識                   | 實戰能力                       |
| 層級     | 帳號永久                   | 主角永久                       |
| 主要用途 | 解鎖、Base Score、研究     | Event Roll、成功率上限、大成功 |
| 成長來源 | 研究、Action、發現物、委託 | Action、Event、遠征            |
| 例子     | 考古學、地理學、香料知識   | 挖掘、檢查、操帆、炮術         |

## 五、副官系統

### 定位

副官是**配置型輔助角色**，取代原本的船長退役 / Soft Prestige 功能。

副官不是另一個主角，也不是世代制角色。副官提供：

- 語言
- 特定 Skill 加成
- 特定 Knowledge 加成
- Action 類型加成
- Event 判定輔助
- 母港派駐效果

玩家主線仍然是培養唯一主角船長。

### 副官設計原則

- 副官提供 Build 差異，不製造重置需求
- 副官可以成長，但成長深度低於主角
- 副官不會退役、不會死亡、不會洗掉玩家進度
- 副官同時是「能力配置」與「大航海味」來源
- 語言主要由副官承擔

### 副官槽位

| 階段                | 可配置副官數 | 設計目的                       |
| ------------------- | -----------: | ------------------------------ |
| 初期                |            1 | 讓玩家理解副官是輔助配置       |
| 中期                |            2 | 開始形成貿易 / 探險 / 海事流派 |
| 後期                |            3 | 建立遠征與跨海域 Build         |
| 大型船 / 艦隊解鎖後 |            4 | 高階配置，不讓早期複雜度爆炸   |

### 副官類型

| 類型   | 主要效果                       | 典型用途                     |
| ------ | ------------------------------ | ---------------------------- |
| 航海長 | 操帆、掌舵、補給、氣象加成     | 遠洋航線、風暴、遠征         |
| 會計長 | 會計、議價、市場判斷加成       | 貿易、商會委託、套利         |
| 探險家 | 挖掘、檢查、發現、考古加成     | 遺跡、發現物、地圖探索       |
| 砲術長 | 炮術、射擊、白兵、護航加成     | 海盜、私掠、海事 Action      |
| 翻譯官 | 語言、情報、港口准入           | 封閉港口、特殊委託、遠方海域 |
| 醫官   | 醫學、疫病、船員損耗、遠征安全 | 長途遠征、危險海域           |
| 造船師 | 船隻改裝、修繕、材料效率       | 船隻 Build、母港造船         |
| 外交官 | 社交、聲望、貴族關係           | 港口准入、貴族委託、外交事件 |

### 副官能力結構

每名副官包含：

```
副官
├── 職能：航海長 / 會計長 / 探險家 / 砲術長 / 翻譯官 / 醫官...
├── 語言：1-3 種
├── 被動加成：常駐，配置後生效
├── 支援技能：特定 Event 或 Action 類型生效
├── 派駐效果：放在母港時生效
└── 信賴度：低速成長，解鎖副官被動節點
```

### 副官成長

副官不使用完整主角式 Skill 樹，只使用簡化成長：

| 成長項 | 作用                         |
| ------ | ---------------------------- |
| 等級   | 提升副官基礎加成             |
| 信賴度 | 解鎖副官被動節點             |
| 專長   | 決定副官強項，不鼓勵萬能副官 |
| 語言   | 招募時固定或透過稀有事件追加 |

### 副官加成範例

```
艾蓮娜・羅西
職能：會計長
語言：義大利語、拉丁語
被動：藝術品交易報酬 +8%
支援：議價 Event Roll +10%
派駐：母港市場收益 +5%
信賴 Lv.3：解鎖「貴族收藏品情報」
```

```
哈桑・伊本
職能：翻譯官
語言：阿拉伯語、波斯語
被動：紅海 / 印度洋情報取得率 +12%
支援：封閉港口交涉 Roll +15%
派駐：圖書館翻譯研究速度 +10%
信賴 Lv.3：解鎖「香料商路傳聞」
```

```
瑪麗亞・岡薩雷斯
職能：航海長
語言：葡萄牙語
被動：遠洋 Action 時間 -6%
支援：風暴 Event Roll +12%
派駐：造船廠遠洋船改裝成本 -5%
信賴 Lv.3：好望角遠征氣象門檻 -1 級
```

| Build  | 配置                     | 方向                         |
| ------ | ------------------------ | ---------------------------- |
| 貿易流 | 會計長 + 翻譯官 + 外交官 | 高收益、港口准入、特殊交易   |
| 探險流 | 探險家 + 翻譯官 + 醫官   | 遺跡、發現物、危險地區探索   |

| 遠征流 | 航海長 + 探險家 + 醫官   | 大型遠征、未知海域、長途挑戰 |
| 造船流 | 造船師 + 會計長 + 航海長 | 船隻改裝、材料效率、航行性能 |

### 副官派駐母港

副官可以不隨行，改為派駐母港提供支援。

| 派駐地        | 可派副官           | 效果                         |
| ------------- | ------------------ | ---------------------------- |
| 圖書館        | 翻譯官、學者型副官 | Knowledge 研究速度、翻譯情報 |
| 市場          | 會計長、外交官     | 商品收益、委託刷新、價格情報 |
| 造船廠        | 造船師、航海長     | 造船速度、改裝成本、耐久修繕 |
| 酒館          | 外交官、會計長     | 副官招募品質、情報出現率     |
| 海軍基地      | 砲術長、醫官       | 護航任務、海事支援、受傷恢復 |
| 醫院 / 診療所 | 醫官               | 疫病事件、船員損耗、遠征安全 |

## 六、海域（Region）系統

### 定位

海域本質上是一個具名 Action 的集合，提供氛圍、場所和區域成長。

海域不是獨立角色，也不會 reset。海域的發展程度由 **Region Familiarity（區域熟悉度）** 體現。

### Region Familiarity（區域熟悉度）

每個海域有一個區域熟悉度，等於該海域所有 Action Mastery 的加總。

採用總和，不用平均，避免懲罰玩家解鎖更多 Action。

```
東地中海 Region Familiarity
  海峽探勘      Mastery 50
  橄欖油貿易    Mastery 30
  希臘遺跡發掘  Mastery 20
  ─────────────────────────
  熟悉度總和 = 100 → Tier 1
```

### MVP Tier 分層

| Tier   | 熟悉度範圍 | 效果                                       |
| ------ | ---------: | ------------------------------------------ |
| Tier 0 |       0-99 | 無加成                                     |
| Tier 1 |    100-299 | 速度 +10%、報酬 +5%                        |
| Tier 2 |    300-599 | 速度 +20%、報酬 +15%、解鎖區域專屬 Event   |
| Tier 3 |       600+ | 速度 +30%、報酬 +25%、解鎖區域 Boss Action |

### 關鍵設計規則

- Region Familiarity 只影響該海域
- 不 spill over 到帳號層
- Knowledge、Captain Skill、Action Mastery 正常永久保留
- 副官的海域加成只在配置或派駐時生效

### 解決「新手村 vs 新地區沒區別」

|                    | 開發成熟的舊海域      | 新開拓海域                     |
| ------------------ | --------------------- | ------------------------------ |
| 可用 Action 數     | 多                    | 少                             |
| Region Familiarity | 高，有速度 / 報酬加成 | Tier 0，無加成                 |
| Mastery 效果       | 已解鎖大量節點        | 從零開始                       |
| 副官需求           | 可用效率型副官刷收益  | 需要語言 / 探索 / 航海副官開路 |
| 主角表現           | 順暢，底盤高          | 吃力，門檻高且事件危險         |

### 海域圈層解鎖

```
早期：西地中海、東地中海
中期：北海、波羅的海、黑海、畢里牛斯灣
晚期：西非、紅海、印度洋
末期：新大陸、東亞、太平洋
```

## 七、Action 系統

### 定位

Action 是玩家的核心操作單位。

每個 Action 都是：

- 具名的
- 有 Mastery 的
- 綁定在特定海域
- 會產出 Knowledge EXP / Captain Skill EXP / 報酬
- 可能觸發 Event

### 玩家操作流程

```
選擇海域
  → 選擇具體 Action
  → 配置船隻 / 副官
  → 開始掛機
  → Action 結束時觸發 Event
  → 判定結果
  → 獲得報酬、EXP、Mastery、發現物或情報
```

### Action 範例

```
海峽探勘
  海域：東地中海
  門檻：地理學 Lv.10 + 測量學 Lv.5
  推薦副官：航海長 / 翻譯官
  報酬：地理學 EXP、測量學 EXP、金幣、海圖碎片
  Event Pool：風暴（操帆判定）、暗礁（掌舵判定）、漁民情報（社交 / 語言判定）
```

```
橄欖油貿易
  海域：東地中海
  門檻：雜貨 Lv.5 + 食品 Lv.5
  推薦副官：會計長 / 外交官
  報酬：金幣、食品 EXP、雜貨 EXP、商會聲望
  Event Pool：議價（會計判定）、貴族訂單（社交判定）、豐收年（市場判斷判定）
```

```
希臘遺跡發掘
  海域：東地中海
  門檻：考古學 Lv.20 + 地理學 Lv.15 + 希臘語支援
  推薦副官：探險家 / 翻譯官
  報酬：考古學 EXP、發現物、藝術品、聲望
  Event Pool：古文字解讀（語言判定）、坍塌通道（檢查判定）、文物鑑定（美術學 / 考古學判定）
```

```
驅離海盜
  海域：黑海 / 北海
  門檻：炮術 Lv.15 + 船隻火力需求
  推薦副官：砲術長 / 醫官 / 航海長
  報酬：金幣、海事聲望、炮術 EXP、白兵 EXP
  Event Pool：砲擊戰（炮術判定）、接舷戰（白兵判定）、追擊（操帆判定）
```

### Action 展示範例（玩家視角）

```
東地中海 [熟悉度 Tier 2 — 速度+20% 報酬+15%]

  ◉ 橄欖油貿易      Mastery 47/99   下個節點：Lv.50 批發模式
  ◯ 海峽探勘        Mastery 12/99
  ◯ 威尼斯藝品商路  Mastery 0/99    🔒 需要：美術學 Lv.15
  🔒 希臘遺跡發掘                  🔒 需要：考古學 Lv.20 + 希臘語支援
```

### Action 解鎖條件

- Knowledge 門檻
- 主角 Skill 門檻
- 前置 Action Mastery
- 海域熟悉度 Tier
- 船隻條件
- 副官語言 / 職能支援
- 遠征或劇情性世界狀態

## 八、Mastery 系統

### 定位

每個 Action 獨立的 Mastery 進度，綁帳號，永久保留。

Mastery 是玩家對特定活動的熟練度，不因切換海域、船隻、副官而消失。

### Mastery 效果原則

- 不只是 +X% 效率
- 改變 Action 性質
- 解鎖新的 Action 變體
- 產生跨海域依賴
- 高等級可讓舊海域變成後期資源地

### 範例：橄欖油貿易 Mastery

```
Lv.20 → 解鎖批發模式（量大利薄的新選擇）
Lv.50 → 有機率觸發「豐收年」事件（需要補給理論才能利用）
Lv.80 → 解鎖跨海域變體：「北海橄欖油轉口」→ 北海多出一個 Action
Lv.99 → 解鎖母港自動商路，不需主角駐守
```

### 範例：希臘遺跡發掘 Mastery

```
Lv.20 → 發現物品質 +5%
Lv.40 → 解鎖「深層遺跡」模式，時間更長，發現物更好
Lv.60 → 觸發「古文字石碑」事件，需要希臘語 / 拉丁語副官
Lv.80 → 解鎖紅海 Action：「古代航路考證」
Lv.99 → 東地中海考古類 Action 大成功額外獲得學術聲望
```

### Mastery 跨海域 Trigger

高等 Mastery 可以在其他海域生成新 Action。

這是系統最重要的咬合點之一，能自然製造跨海域依賴，不需要額外硬塞任務線。

範例：

```
東地中海「橄欖油貿易」Mastery 80
  → 北海解鎖「橄欖油轉口貿易」

北海「造船木材採購」Mastery 70
  → 西非遠征船隻改裝成本下降

西非「熱帶植物記錄」Mastery 60
  → 母港醫院解鎖新藥研究

紅海「香料商路」Mastery 80
  → 印度洋解鎖高階香料套利 Action
```

## 九、判定公式

### 流程

```
Action 結束
  → 從 Event Pool 隨機撈一個 Event
  → Event 決定使用哪個 Captain Skill
  → 套用 Knowledge / Mastery / Ship / 副官加成
  → 判定結果
```

### 公式

```
Base Score = f(Knowledge 加成, Mastery Effect, 船隻 Status, 副官被動)
Difficulty Threshold = Action 難度（固定值）

Event 決定使用哪個 Captain Skill：
  CS = 主角 Captain Skill
  ESR = Event Skill Requirement
  Officer Support = 副官支援修正

  Effective CS = CS × (1 + Officer Support)

  Max Roll = Effective CS × (Effective CS / ESR)
           = Effective CS² / ESR

  Min Roll = Effective CS × (Effective CS / (Effective CS + ESR))
           = Effective CS² / (Effective CS + ESR)

  Roll Score = rand(Min Roll, Max Roll)

Result = (Base Score + Roll Score) / Difficulty Threshold
```

### 結果判定

| Result 範圍 | 等級   | 效果                         |
| ----------- | ------ | ---------------------------- |
| < 1.0       | 失敗   | 報酬打折，無倒扣             |
| 1.0-2.0     | 成功   | 正常報酬                     |
| ≥ 2.0       | 大成功 | 額外獎勵、稀有發現、額外情報 |

### 數值直覺

| Effective CS | ESR | Min Roll | Max Roll | 意義                              |
| -----------: | --: | -------: | -------: | --------------------------------- |
|           25 |  50 |      8.3 |     12.5 | 新手碰到超標 Event，幾乎只靠 Base |
|           50 |  50 |       25 |       50 | 剛好及格，Roll 有存在感但不穩     |
|          100 |  50 |     66.7 |      200 | 老練船長，穩定推進大成功區間      |
|           50 |  25 |     33.3 |      100 | 高素質應對低要求，能衝大成功      |

### 設計意圖

- Base Score 決定穩定底盤
- Roll Score 決定上限
- Captain Skill 超過 ESR 後超線性成長，角色成長有感
- 副官不取代主角，只修正 Effective CS 或 Base Score
- 船隻提供硬體底盤，避免 Build 只有技能數值

### 副官在公式中的角色

副官加成分兩類：

| 類型     | 影響位置     | 範例                                       |
| -------- | ------------ | ------------------------------------------ |
| 被動加成 | Base Score   | 藝術品交易 Base +5、紅海情報 Base +8       |
| 支援加成 | Effective CS | 風暴 Event 操帆 +12%、議價 Event 會計 +10% |

副官不直接給最終倍率，避免變成單純堆數值。

### 資訊透明要求

玩家必須能看到：

```
[ 希臘遺跡發掘 ]
  Base Score：47
    考古學 Knowledge  → +15
    地理學 Knowledge  → +8
    Action Mastery    → +12
    船隻設備          → +7
    探險副官被動      → +5

  Event：古文字解讀
  使用 Skill：檢查
  主角檢查 Skill：34
  副官支援：希臘語翻譯 +10%
  Effective CS：37.4
  Roll 範圍：16 ~ 28
  Threshold：50
  預期成功率：約 82%
```

## 十、Event 系統

### 定位

Event 是 Action 結束時隨機觸發的附加判定。

Event 決定：

- 使用哪個 Captain Skill
- 哪個副官能支援
- 報酬浮動
- 額外 EXP
- 是否產生發現物、情報、特殊委託

### Event 範例

```
Action：海峽探勘
Event Pool：
  ├── 遭遇風暴     → 操帆判定   成功: +操帆 EXP多  失敗: +修繕 EXP少
  ├── 發現暗礁     → 掌舵判定   成功: +掌舵 EXP多  失敗: +修繕 EXP少
  ├── 漁民情報     → 社交 / 語言判定 成功: +海圖碎片 失敗: +少量地理學 EXP
  └── 平安無事     → 無額外判定
```

```
Action：希臘遺跡發掘
Event Pool：
  ├── 古文字石碑   → 檢查 + 希臘語支援
  ├── 地下空洞     → 挖掘 + 探險副官支援
  ├── 文物鑑定     → 發現 + 美術學 Knowledge
  └── 坍塌危機     → 掌舵 / 修繕式危機判定
```

### Event 設計原則

- Event 不獨立於 Action 判定，而是影響 Roll Score 的計算基準
- 失敗不倒扣，只是報酬打折和 EXP 縮減
- Event 是 Captain Skill 成長的主要來源
- 副官透過 Event 支援產生 Build 差異
- 語言適合放在 Event / 港口 / 委託門檻，而非全部塞進主角技能

## 十一、遠征系統（整合考試）

### 定位

遠征對應 Melvor 的 Dungeon，是多系統門檻的大型挑戰。

遠征成功後永久改變世界狀態，但不 reset 任何進度。

### 遠征功能

- 多系統整合確認關卡
- 成功後永久解鎖新海域、新港口、新 Action
- 自然製造跨海域依賴
- 要求主角、船隻、副官、Knowledge、Mastery 同時達標
- 不消耗主角，不強制退役

### 範例：開闢好望角航路

```
大型遠征：開闢好望角航路

需求：
  Knowledge：地理學 Lv.40 + 操帆理論 Lv.35 + 補給理論 Lv.30 + 氣象學 Lv.20
  Region Familiarity：西非 Tier 2 以上
  主角 Skill：操帆 + 掌舵 + 補給 合計 200+
  船隻：遠洋船型，耐久 / 載貨 / 補給達標
  副官：航海長或葡萄牙語副官至少一名
  物資：北海橡木 ×100 + 東地中海糧食 ×50
  Mastery：至少 3 個西非 Action 的 Mastery 達 50+

報酬：
  解鎖印度洋海域
  解鎖印度洋香料商路
  所有遠洋貿易 Action 報酬 +10%
  主角獲得稱號「航路開拓者」
  酒館副官池追加印度洋相關副官
```

### 範例：新大陸初航

```
大型遠征：新大陸初航

需求：
  Knowledge：地理學 Lv.60 + 天文學 Lv.50 + 補給理論 Lv.45 + 氣象學 Lv.40
  Region Familiarity：西非 Tier 3 + 北海 Tier 2
  主角 Skill：操帆 + 補給 + 發現 合計 300+
  船隻：大型遠洋船隊配置
  副官：航海長 + 醫官推薦，西班牙語 / 葡萄牙語支援

  Mastery：好望角航路 Mastery 70+

報酬：
  解鎖新大陸海域
  解鎖貴金屬新商品鏈
  解鎖生物學高階發現物
  解鎖殖民地供應委託
```

| 結果   | 效果                                        |

| 失敗   | 報酬打折，獲得部分 EXP / 情報，不倒扣       |

## 十二、船隻系統

### 定位

船隻是主角的核心裝備，也是 Action 與遠征的硬體門檻。

船隻不只是數值道具，而是 Build 的一部分。

### 船隻主要屬性

| 屬性     | 作用                         |
| -------- | ---------------------------- |
| 速度     | Action 時間、航行效率        |
| 載貨     | 貿易收益、遠征物資上限       |
| 耐久     | 事故損失降低、遠征穩定性     |
| 火力     | 海事 Action、海盜 Event      |
| 操控     | 暗礁、追擊、狹窄航道         |
| 補給     | 長距離遠征門檻、失敗折損降低 |
| 船員容量 | 特定 Action 與遠征需求       |
| 改裝槽   | 放置船隻模組、強化特化方向   |

### 船隻類型草案

| 船型       | 方向           | 適用玩法             |
| ---------- | -------------- | -------------------- |
| 小型帆船   | 便宜、快速     | 早期探索、短程貿易   |
| 商用帆船   | 高載貨         | 貿易、套利、物資搬運 |
| 探險船     | 高補給、高操控 | 遠征、海圖、未知海域 |
| 武裝商船   | 平衡載貨與火力 | 危險海域貿易         |
| 戰艦       | 高火力、高耐久 | 海事、護航、私掠     |
| 大型遠洋船 | 高補給、高載貨 | 晚期遠征、新大陸航線 |

### 船隻與副官

副官可以強化船隻方向：

```
航海長 → 遠洋船 Action 時間下降
造船師 → 改裝成本下降、船隻耐久提升
砲術長 → 火力屬性轉換成更高海事 Base Score
醫官   → 長途遠征船員損耗降低
會計長 → 商船載貨收益提升
```

## 十四、核心循環

### 主循環

```
1. 選擇海域 → 選擇具體 Action
2. 配置船隻 / 副官
3. 開始掛機
4. Action 結束 → Event 判定
5. 獲得報酬、Knowledge EXP、Captain Skill EXP、Action Mastery
6. Knowledge 成長 → 解鎖新 Action / 設施 / 遠征門檻
7. Captain Skill 成長 → Roll 上限提升 → 更容易大成功
8. Action Mastery 成長 → 解鎖 Action Feature / 跨海域 Action / 熟悉度
9. Region Familiarity 升 Tier → 該海域速度 / 報酬 / Event 提升
10. 招募與配置副官 → 語言、支援、Build 差異
11. 準備遠征 → 解鎖新海域與世界狀態
```

### 玩家成長感

```
我掛 Action
  → 主角 Skill 變強
  → Knowledge 變高
  → Action Mastery 變高
  → 海域更熟
  → 船更好
  → 副官配置更多
  → 能跑更遠
  → 世界變大
```

### 跨海域依賴的四重來源

1. **Knowledge 門檻**：某個 Action 需要其他海域才能有效練出的 Knowledge
2. **Mastery 跨海域 Trigger**：高等 Mastery 在別的海域生成新 Action
3. **遠征多海域門檻**：大型遠征需要多個海域的 Mastery、物資、Knowledge
4. **副官語言 / 情報**：特定海域需要特定語言或副官支援才能順利開拓

## 十五、Feedback 與資訊透明原則

任何 Grind 都要讓玩家清楚看到：

1. 我現在在推哪個長期目標
2. 哪些 Knowledge / Skill 正在發揮作用
3. 哪個副官正在提供支援
4. 這次失敗為什麼失敗
5. 下一個明確解鎖是什麼
6. 這個 Action 會讓其他系統變強在哪裡

### 進度條顯示範例

```
[ 執行中：威尼斯藝品商路 ]  ████████░░  80%
  預計報酬：金幣 480 + 藝術品 ×3
  獲得 EXP：美術學 +24  貴金屬 +8  會計 +12
  Region Familiarity 貢獻：東地中海 +1 Mastery EXP

[ 主角船長 ]
  會計：72/75 → 下一節點：批量議價
  社交：41/50 → 下一節點：貴族委託成功率 +5%

[ 隨行副官：艾蓮娜・羅西 ]
  支援：藝術品交易報酬 +8%
  語言：義大利語、拉丁語
  信賴度：Lv.2 → Lv.3 解鎖「貴族收藏品情報」

[ 東地中海 Familiarity ]
  Tier 2 (380/600) → 下一 Tier: 速度+30% 報酬+25%
```

## 十六、MVP 範圍

### MVP 應包含

| 系統      | MVP 內容                               |
| --------- | -------------------------------------- |
| 主角船長  | 永久 Skill，至少 6-8 種                |
| Knowledge | 交易 / 學術 / 航海三類，各 4-6 種      |
| 副官      | 6-10 名，1-2 個副官槽，語言與支援加成  |
| 海域      | 西地中海、東地中海、北海或黑海         |
| Action    | 每海域 4-6 個具名 Action               |
| Mastery   | 每 Action 20 / 50 / 80 / 99 節點草案   |
| 船隻      | 3-5 種船型，基本改裝                   |
| 母港      | 造船廠、市場、酒館、圖書館、倉庫       |
| 遠征      | 1 個大型遠征：開闢西非航線或好望角前置 |

### MVP 不做

- 不做船長退役
- 不做 Prestige / Reset
- 不做多主角輪替
- 不做完整艦隊管理
- 不做大量副官養成樹
- 不做複雜港口經濟模擬
- 不做 PvP
- 不做死亡懲罰

## 十七、設計風險與對策

| 風險                          | 對策                                                    |
| ----------------------------- | ------------------------------------------------------- |
| Knowledge 太多變雜訊          | 每個類別有明確 Breakpoint，小等級給效率，大等級給新玩法 |
| 副官變成另一套角色管理        | 限制副官深度：職能、語言、被動、信賴度，不做完整技能樹  |
| 語言變成麻煩鑰匙              | 語言主要作為加成與替代門檻，不讓玩家因缺語言完全卡死    |
| 海域變成平行清單              | Mastery 跨海域 Trigger + 遠征多海域門檻 + 副官語言需求  |
| Region Familiarity 變成純填條 | Tier 升級附帶專屬 Event、Boss Action、港口委託          |
| Captain Skill 存在感低        | Roll 公式超線性成長，高 Skill 對大成功率有明顯影響      |
| 副官數值膨脹                  | 副官提供支援修正，不直接給最終報酬倍率                  |
| 船隻存在感低                  | 船隻作為遠征硬門檻與 Action Build 核心，不只是速度道具  |
